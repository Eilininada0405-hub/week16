# こころのいろ診断

いくつかの質問に答えると、今の自分に近い「こころのいろ」タイプがわかる性格診断サイトです。

## 要件分解表

| 項目 | 内容 |
|---|---|
| 何を作るか | 8つの質問から4種類の性格タイプを診断するサイト |
| 画面に出すもの | スタート画面、質問・進捗、診断結果とひとことアドバイス |
| できる操作 | 診断を始める、選択肢を選ぶ、前の質問に戻る、最初からやり直す |
| 持つ状態 | 現在の質問番号、各質問の回答、診断中か結果表示中か |
| 使う技術 | React、`useState`、JavaScript、CSS、Vite |
| つまずきそうな所 | 回答の変更や戻る操作で得点がずれないようにし、回答から結果を正しく決める |

## 起動方法

```sh
npm install
npm run dev
```

## ビルド

```sh
npm run build
```

Vite の `base: './'` を設定しているため、ビルド成果物は相対パスで配信できます。

## GitHub Pages

`main` ブランチへの push で GitHub Actions がビルドし、GitHub Pages へデプロイします。リポジトリの Settings → Pages で、公開元を **GitHub Actions** に設定してください。
